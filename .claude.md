## 🗄️ Database Schema — Key Tables

### Core Entities
```sql
users           (id UUID PK, email, password_hash, role, is_active, must_change_pw)
students        (id UUID PK, user_id FK, student_code, full_name_ar, full_name_en,
                 national_id, specialization, enrollment_year, current_level,
                 cgpa, total_credits_passed, academic_status, semesters_enrolled,
                 total_warnings, consecutive_warnings)
doctors         (id UUID PK, user_id FK, full_name_ar, full_name_en, academic_title,
                 department_id FK)
departments     (id UUID PK, name_ar, name_en, code)
```

### Academic Workflow
```sql
courses         (id, code, name_ar, name_en, credits, category, level,
                 is_mandatory, is_active, department_id)
semesters       (id, academic_year, semester_type, status, start_date, end_date,
                 registration_start, registration_end)
course_offerings(id, course_id, semester_id, doctor_id, section, capacity,
                 enrolled_count)
enrollments     (id, student_id, offering_id, status, attempt_number,
                 midterm_grade, coursework_grade, practical_grade, final_exam_grade,
                 total_grade, letter_grade, grade_points, is_counted_in_gpa,
                 grade_locked)
```

### Supporting Tables
```sql
attendance_sessions  (id, offering_id, session_date, session_type)
attendance_records   (id, session_id, enrollment_id, is_present, is_excused)
gpa_history          (id, student_id, semester_id, semester_gpa, cumulative_gpa,
                       classification, credits_earned)
academic_warnings    (id, student_id, semester_id, warning_type, cgpa_at_warning)
notifications        (id, user_id, title, message, type, is_read, related_id)
announcements        (id, title, body, target_role, is_pinned, created_by)
```

### Grade Calculation (server-enforced)
```
total_grade = midterm(20%) + coursework(10%) + practical(10%) + final(60%)
Letter grade assigned by DB trigger from total_grade:
  ≥ 97 → A+ | ≥ 93 → A | ≥ 90 → A- | ≥ 87 → B+ | ≥ 83 → B | ≥ 80 → B-
  ≥ 77 → C+ | ≥ 73 → C | ≥ 70 → C- | ≥ 67 → D+ | ≥ 60 → D | < 60 → F
```

## 🔌 API Endpoints Map

### Auth (`/api/v1/auth`)
| Method | Path | Description |
|---|---|---|
| POST | `/login` | Returns `accessToken` + `refreshToken` + `user` + `profile` |
| POST | `/logout` | Invalidates refresh token |
| POST | `/refresh` | Exchanges refresh token for new access token |
| GET | `/me` | Returns current user + profile |
| PUT | `/change-password` | Requires `currentPassword` + `newPassword` |

### Student (`/api/v1/student`)
| Method | Path | Description |
|---|---|---|
| GET | `/dashboard` | Student stats, current semester, schedule, GPA history, warnings |
| GET | `/courses/:semesterId` | Available courses with `can_register`, `already_registered`, `register_block_reason` |
| POST | `/enroll` | `{ offeringId }` — bylaw-checked enrollment |
| DELETE | `/enroll/:enrollmentId` | Drop course |
| GET | `/schedule/:semesterId` | Current schedule with attendance |
| GET | `/transcript` | Full transcript, GPA history |
| GET | `/graduation-status` | Eligibility checklist + honors check |
| GET | `/notifications` | Paginated notifications |
| PUT | `/notifications/:id/read` | Mark one read |
| PUT | `/notifications/read-all` | Mark all read |
| GET | `/notifications/unread-count` | `{ count: N }` |

### Doctor (`/api/v1/doctor`)
| Method | Path | Description |
|---|---|---|
| GET | `/dashboard` | Doctor info, courses, pending grades, analytics |
| GET | `/courses/:offeringId/roster` | Full roster with grades + attendance |
| PUT | `/enrollments/:enrollmentId/grades` | Enter grades (midterm/coursework/practical/final) |
| POST | `/courses/:offeringId/attendance` | Record session attendance |
| GET | `/notifications` + PUT read/unread-count | (same pattern as student) |

### Admin (`/api/v1/admin`)
| Method | Path | Description |
|---|---|---|
| GET | `/dashboard` | System-wide stats, specialization breakdown, recent warnings |
| GET/POST | `/students` | List with filters / search |
| GET | `/students/:id` | Full detail with transcript + warnings + graduation |
| GET/POST | `/users` | User management (create admin/doctor/student) |
| GET/PUT | `/semesters` | List + status lifecycle transitions |
| GET/PUT | `/courses` | Course catalog management |
| GET/PUT | `/registration` | Open/close registration windows |
| POST | `/enroll` | Admin override enrollment |
| GET | `/reports/academic` | GPA distribution, top students, dismissed list |
| GET/POST | `/announcements` | Bulletin board |
| GET + PUT | `/notifications` | Admin notification feed |

### Shared (`/api/v1`)
| Method | Path | Description |
|---|---|---|
| GET | `/semesters` | All semesters (used by student course reg) |
| GET | `/departments` | Department list (used for doctor creation) |
| GET | `/announcements` | Public announcements |

## 🔧 How to Run

```bash
# Quick start (production-like)
docker compose up -d --build

# Access points
# Frontend:   http://localhost:8080
# Backend:    http://localhost:3000/api/v1
# Grafana:    http://localhost:3050  (admin / admin123)
# Prometheus: http://localhost:9090

# Development (frontend hot-reload)
cd frontend && npm start          # port 3000 (or 3001 if backend is on 3000)
cd backend && npm run dev         # port 3000 with nodemon

# Rebuild frontend only
docker compose up -d --build frontend

# View logs
docker compose logs -f backend
docker compose logs -f postgres
```
